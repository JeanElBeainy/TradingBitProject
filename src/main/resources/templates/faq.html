Frequently Asked Questions (FAQ)

What is TradingBit.net?

TradingBit.net is a simulated cryptocurrency trading platform. It was created as a personal project by a university student to demonstrate skills in web development, particularly with Java and the Spring Boot framework It is not a real financial service.

Can I use real money or deposit actual crypto?

Absolutely not. All functionalities, including account balances, trading, and swapping, are purely for simulation. No real money or cryptocurrency is ever used, stored, or transacted on this platform. The values shown are for demonstration purposes only.

Where does the cryptocurrency price data come from?

The market data, such as prices and charts, is fetched from CoinMarketCap API. This data is for informational purposes and may be subject to delays or inaccuracies. It should not be used for making real-world financial decisions.

How does the "Swap" feature work?

The swap feature simulates the exchange of one cryptocurrency for another based on their current market prices. When you perform a swap, the system calculates the equivalent amount of the destination asset, subtracts a small simulated transaction fee (0.1%), and updates your portfolio balance accordingly. Again, this is all a simulation.

Is my account information secure?

Security is a priority. User passwords are not stored in plain text. They are hashed using bcrypt via Spring Security. However, as this is a portfolio project, we strongly advise you to use a unique password and not one that you use for your real financial or personal accounts.

How can I try the program on my machine?

You can clone this repositoryand test it out for yourself, and remember to read the README file carefully.
